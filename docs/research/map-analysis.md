## 网页端渲染映射（PROPOSED，2026-11-26 重构）

- 逻辑世界：128×96 格、TILE=64 → 8192×6144；原图 385×289 按约 3:1 映射。
- 背景：`arena.png`（2048×1536）由全图 ground 调色 + pathing 墙体雪檐轮廓生成，三端渲染器共用。
- 碰撞：`blocked.bin` 128×96，仅用 WPM bit 0x02（不可通行）；不再使用地表 ID 误判。
- 可通行连通区：16 个（游戏格分辨率）；英雄出生点均置于同一大房间 (30,16)/(62,16)/(38,34)/(50,28)，保证可互相到达。
- 树木：原版 4,282 棵 `WTst` 数据保留在 `doodads.json`，但网页渲染已移除，避免遮挡房间轮廓。
