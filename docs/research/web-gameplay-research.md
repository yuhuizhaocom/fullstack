## 2. 核心玩法（HIGH / MED）

### 2.1 对局本质（猫鼠游戏）
- 精灵：找安全点位建造基地，发展经济、建墙防守、升级科技，拖到后期；不是正面作战。（18183 / 3DM，与本地 JASS 的房间堵墙机制一致 → HIGH）
- 巨魔：搜图、追击、拆家、打断精灵发育；越早找到精灵越占优势。（18183 / 3DM → HIGH）
- 精灵胜利：杀死巨魔；巨魔胜利：消灭所有精灵势力。（3DM → HIGH，与本地 `victory-rules.md` 一致）
- 精灵死亡 3 秒后其所有单位消失（3DM；本地 VERIFIED 为 2 秒清理，略有版本差异 → MED）

### 2.2 模式与规则（3DM 指令列表 → HIGH，与本地 JASS 交叉验证）
- 模式指令：`-old`（默认）、`-yoyolook`、`-new`、`-team`、`-solo`、`-defend`、`-fast`、`-run`（逃跑模式：精灵存活 16 分钟胜）。
- 规则指令：`-single`（默认）、`-double`（巨魔死转幽灵狼，两狼都死则巨魔败）、`-fix`（精灵 30 秒选定点位）、`-race`、`-defend`、`-solo`、`-duet`、`-survive`、`-revive`。
- 本地 JASS 已验证：4 模式 × 9 规则，巨魔出现 30/45 秒，规则枚举与胜负判定一致。

### 2.3 精灵玩法要点（MED）
- 开局选点：入口少、空间足够大、不易被第一时间搜到、能形成多层防线；不要犹豫浪费发育时间。
- 三条发育线必须同步：经济（修墙/补塔/升级的资源）、防线（前期基础墙→中期多层→后期塔+科技）、科技（低级建筑撑不住后期）。
- "升塔，升塔，升塔"被 3DM 攻略列为精灵进阶第一条。
- 会玩的精灵帮不会玩的精灵起塔、教应对巨魔进攻（3DM）。
- 心理战：造假建筑误导巨魔、非常规点位、假离开再回头。

### 2.4 巨魔玩法要点（MED）
- 3DM 攻略：前期尽量节省生存上的金钱投入，优先升级武器和手套；中期出巨魔巫医并藏在隐匿位置，拉回巨魔。
- 18183：搜图路线清楚、判断准确、发现后持续压制；拆家要打关键点（入口墙、塔覆盖核心区、经济建筑），持续施压让精灵消耗资源在防守上。
- 搜狗百科摘要：巨魔靠攻击敌方建筑（主要是墙）得钱买装备；可买剑+加速，或剑+血量装（早期版本巨魔血量低）。

### 5.2 新增玩法要点（MED）
18183 第二篇（与 3DM/18183 第一篇互相印证）：
- 精灵前期：快速找安全点 → 尽快建基础建筑 → **先把入口封住** → 发展经济 → 补防御塔/墙 → 不要过早暴露位置。
- 精灵中期：升级墙体、提升塔输出、继续经济、注意**修理建筑**、队友互相提醒巨魔位置、建筑不要摆太乱。
- 巨魔前期：搜常见藏点、观察地图空位与建筑痕迹、发现后立刻压制、优先攻击关键入口、不要被拖太久、逐个击破。
- 巨魔中后期：优先拆经济建筑、不要只打最厚的墙、找薄弱点、持续压制精灵修理节奏、提升自身装备属性、优先击破落单/发育差精灵。
- 新手误区（精灵）：找位置太慢、只顾经济不造防御、入口没封好、不修建筑、位置太暴露。
- 新手误区（巨魔）：搜图没路线、发现后不持续压制（打几下就走给精灵修复时间）、只打最硬的地方、前期节奏慢、不提升自身能力。
